## v0.5.91 追加

撃破確率計算に「敵EX許容回数」を追加しました。既定値は0です。0なら敵EX1回目で失敗、1なら1回目を許容して2回目で失敗、nならn+1回目で失敗します。

許容された敵EXは共有敵EXゲージを0へ戻し、その敵／お供の行動機会を消費します。敵EXそのもののダメージや追加効果は撃破率には反映しません。今後のWikiチャート験算では、特記がなければ敵EX許容回数0を使用します。
