# ORECA Tools

GitHub Pages で公開できる静的Webアプリです。サーバー処理や外部ライブラリは不要です。

## 現在の機能

- ダメージ計算
  - 攻撃力・攻撃補正
  - 属性・技倍率・ヒット数
  - アンデッド補正
  - 防御補正・ダメージ軽減
  - 最低ダメージ / 最高ダメージ

- 最適遭遇条件
  - モンスター／敵パーティを検索
  - Lv合計30（Lv10×3）固定
  - ★合計3～12を全探索
  - 複数章は章別に最適条件を表示
  - Normal／Rare／通常Boss／独立ランダムBossを統合

- 技発動率計算
  - 通常4リール／BOSS8リール／シモン3リール
  - Nターン後の発動回数分布・期待値
  - 目標回数までのターン別初達成確率・累積確率
  - 技発動後の「ミスに変化」「ミスに変化+再行動」
  - 猿／牛の変化発動率
  - シモン（投げナイフ／投げオノ／悪魔の心臓）
  - ロック（3種コンボ／コンボフィニッシャー）

- 撃破確率計算
  - 敵HP・属性・素早さ
  - 味方1～3体
  - モンスター選択プリセット
  - 複数ターン／同行動
  - 攻撃力・素早さバフ／デバフ
  - 敵防御補正
  - 毒・猛毒
  - 敵行動効果（攻撃・素早さデバフ、敵の攻撃・防御・素早さアップ、回復）
  - 素早さによる行動順
  - 最後の味方行動までの撃破確率

## GitHub Pagesで公開

1. このフォルダの中身をGitHubリポジトリのルートへアップロード
2. GitHubのリポジトリで `Settings` → `Pages`
3. `Build and deployment` の Source を `Deploy from a branch`
4. Branchを `main`、Folderを `/(root)` にして Save
5. 表示された公開URLを開く

相対パスだけを使っているため、GitHub PagesのプロジェクトURL配下でも動作します。

## 更新時

Service Workerはオンライン時に新しいファイルを優先する network-first です。バージョン更新時は `package.json`、`assets/version.js`、`service-worker.js`、`CHANGELOG.md` を更新します。

## ローカルテスト

```bash
npm test
```

HTMLはES Modulesを使用するため、ローカル確認では簡易HTTPサーバーを使用してください。

## v0.4.10 計算コア監査

撃破確率計算の内部処理をダメージ計算仕様と照合し、攻撃力バフの継続ターン、通常乱数の整数化、小数技倍率の浮動小数誤差を修正しました。

固定攻撃の基本順序は、実効攻撃力 → 技倍率 → 第1属性 → 第2属性 → アンデッド補正 → 通常乱数 → 防御補正です。各段階で整数化します。

## v0.4.9 UI

バフ／デバフの対象は、`1`、`2`、`3`、`1/2`、`1/3`、`2/3`、`1/2/3`からプルダウンで選択します。味方人数に応じて有効な組み合わせだけを表示します。

攻撃力バフはダメージ計算と同じ表記です。乗算は最終倍率を直接入力し、`150%` は攻撃力×1.5、`200%` は×2.0です。加算は `+30 ATK` のように表示します。
## v0.4.11 プリセット整理

キャラクターと主要技は、Wikiの旧章・新章/?章のバトル入手チャートでの使用頻度を基準にカテゴリ内で並べています。同系統の忍法、ポイント、ダークバハムートの4属性ブレスは連続して表示します。

「その他」カテゴリは悪疫グラスだけです。とけるいき・どくかみつきは攻撃技、吸いつくしはバフ・強化技に分類しています。ポイント系はEX2相当だけを残し、画面上ではEX表記を付けません。



## v0.4.12 追加技・対象初期値

- アイテムパーツ: 自身の攻撃+25、素早さ+60（3ターン）。
- 風車: 1発=ATK×0.6+SPD×0.15、攻撃回数はSPD20ごとに増加（最低1、最大10）。
- ロキブランド: デフォルト対象=全員。太陽讃歌: デフォルト対象=1/2。

## v0.5.0 最適遭遇条件

以前作成した敵出現確率計算をWeb版へ移植しました。モンスターまたは敵パーティを指定すると、Lv合計30固定で★合計3～12を比較し、出現章ごとの最大確率と最適★合計を表示します。

確率は「敵候補一覧へ対象が1回以上含まれる確率」であり、候補から実際に選択して戦う確率ではありません。全パーティ解禁・条件モンスターなしを基礎条件とします。

## v0.5.1 技発動率計算

以前Googleスプレッドシート＋Apps Scriptで作成した技発動率計算をWeb版へ移植しました。通常・BOSS・特殊処理（シモン／ロック）、目標発動回数まで、猿／牛の変化発動率を同じORECA Tools内で利用できます。入力は端末内へ自動保存されます。


## v0.5.4 モンスタープリセット技の表示

- モンスタープリセットで使う非主要技を「その他」に追加。
- モンスター選択時、自動設定された技名を技プリセット欄へそのまま表示。
- キャミネコの属性別技、行動スキップにも対応。

## v0.5.3 撃破確率プリセットの固定化

撃破確率計算では、主要技プリセット選択時の効果詳細を固定し、手動入力時だけ編集欄を表示します。味方モンスターには★数・属性を追加し、ロキブランド（★4）と太陽讃歌（火属性）の対象を自動判定します。

## v0.5.2 最適遭遇条件の絞り込み

対象選択欄に章と★のフィルターを追加しました。モンスターは★1～4、敵パーティは★3～6／★7～9／★10～12で絞り込めます。章・★・名前検索は併用できます。これらは候補一覧の絞り込みのみで、選択後の最適条件計算は全出現章・★合計3～12を従来どおり比較します。
